# 光互联建模(阶段 1)

> 三种光拓扑(LPO / CPO / retimed 模块)是同一条链拆法不同:
> Host TX → 电段 A → E/O → 光纤 → O/E → 电段 B → Host RX。阶段 1 只做两件事:
> 光路三个块作为级联 H(f) 进现有信道,O/E 之后注入随光功率变化的噪声,两个引擎都接。
> 不做重定时、不做 L-I 非线性、不做 TDECQ、不算功耗(见 `ROADMAP.md`)。

### 2. 功率尺度约定(铁律 3 能过的前提)

- 电波形**不**被光功率重标;`oma_dbm` + `er_db` 只决定四个电平各自的光功率
  P_low = OMA/(ER−1),P_high = ER·OMA/(ER−1),内电平按三等分(阶段 1 没有 L-I 曲线)。
- 到达光电二极管节点的**直流外电平间距**(`tx.swing × |H_a(0)| × ΣFIR`)对应光电流 R·OMA,
  由此得 `volts_per_amp`;瞬时功率 P(t) = P_mid + y(t)/(R·volts_per_amp),钳在 ≥0。
- 级联的 `ref_gain` 是各段理想值之积(电段 0.5、光块 1.0):两段理想电信道级联 H = 0.25
  而 `loss_at` 报 0 dB;一个 Touchstone 自级联 `loss_at` 恰为单段 2 倍。不这样做的话
  "插损"每多一段就多 6 dB 分压器,和物理无关。
- **噪声注入点在光电二极管电流节点,O/E 响应之前**(用户计划里写的是 O/E 之后)。原因:
  散粒、RIN、TIA 三项都是 TIA 输入端的电流噪声,放在 O/E 之前才让 TIA 带宽决定噪声带宽;
  放在之后噪声带宽就是仿真采样率的一半(随 osr 变的伪量)。每采样 σ² = S(P)·f_s/2,经 O/E
  后留下 S·B_noise(TIA),与 osr 无关。

### 3. 统计引擎的逐电平核:两次修正

1. **名义功率版**(计划原文):σ_k² = [2qR·P_k + RIN(R·P_k)² + i_n²]·B 直接当第 k 电平的核。
   ADC 收端实测它在 ER 6 dB 悲观到 1.4–2.15×(OMA −6/−4 dBm),ER 3 dB 时 1.0。
2. **二阶矩版**(现用,`slicer_sigma_per_level`):判决样本 = Σ_n g[n]·ν(t_s−n),
   g 是阶段 2 冲激(O/E、B 段、CTLE、VGA、上采样 FFE),ν 的方差跟着**那个采样时刻**的光功率走。
   给定发送电平 k,沿滤波器记忆的功率均值是 pre-PD 脉冲 p1 乘电平、方差是邻符号 ISI 功率:
   σ_k² = Σ g²·S(E[P|k], var[P|k])。对时域引擎自己的判决流按发送电平分组实测 σ,
   二阶矩版四个电平全部在 **2% 内**(ER 3 与 6 dB 都是),名义版底电平低 30%、顶电平高 20%。
3. 二阶矩对了之后 BER 比值反而变成统计引擎**乐观**(ADC PAM4:0.88 / 0.71 / 0.63,
   ER 3 / 4.5 / 6 dB,OMA −6 dBm;OMA −4 dBm:0.88 / 0.67 / 0.55)。原因是每个电平的噪声
   其实是**高斯尺度混合**:σ 随 ISI 图样在均值附近 ±30% 摆动,匹配了方差的单个高斯低估它的尾部
   (Q≈3.2 处约 2×)。要收到 1.5× 以内需要按 ISI 图样分箱的核 —— 这就是阶段 1 的判决:
   **逐电平 σ 近似在三个 ER 点都过 2×,ISI 分箱核是下一步而不是现在。**

### 7. 重定时串联(阶段 2)

- `TopologyConfig.retimer: none | both`,`retimer_rx: RxConfig`,`retimer_tx: TxConfig`。`engine/cascade.py`
  把链切成 host TX → 段 A → 重定时 RX | 重定时 TX → 光路(两端理想 0.5 分压段)→ 重定时 RX |
  重定时 TX → 段 B → host RX 三段;每段 `run_time_link(seg_cfg, symbols=上一段判决)`,
  判决流来自 `SimResult.extras["decisions"]`(`score()` 打过分的用户域判决,从 warmup 起对齐;
  2026-10-04 起 `score()` 对整 UI 周跳按段重对齐计分,但这条流仍是接收机原样输出,不重排 —— 某段若周跳,端到端会读成机会水平),
  段 k 的种子 = seed + k 使噪声独立;端到端 = host 判决 vs host 符号流,从 Σwarmup 起比对。
- `symbols=` 只收整数索引(`check_symbols`:浮点数组即波形,拒收),回到波形域只经 `tx/builder.py`
  (铁律 5,`test_domain_boundary.py` 继续通过);给 PRBS 自己的序列时与不给逐位相同(时域两条路径 + 静态链路)。
- 统计版本:每段 `run_statistical`,ADC 收端没有时域抽头时用时域引擎的 MMSE 起始 FFE(`initial_ffe_taps`),
  合成 1 − ∏(1 − pᵢ)。GUI「Optical」页和 Android「Optical reach」study 都走这条快路。
- **全刻度陷阱**:同一个 `retimer_rx` 既收段 A(增益 0.5)又收光路(0.25),host RX 未重定时看整条链(0.25)、
  重定时后看段 B(0.5);`adc.fullscale` 不跟着改就削波 —— 第一次跑三段时段 A 的 BER 4e-4 就是这么来的。
- 示例 33(同光路、同 ADC 收端、KP4 1e-15):reach LPO 8 dB **159 m** / DSP retimed **256 m** / CPO 4 dB **214 m**;
  杠杆表(基线 LPO 8 dB、RIN −143,100 m):电段 8→4 dB +82 m、RIN −143→−148 +109 m、重定时 +132 m,三者一起 +191 m
  (单杠杆之和 +322 m)—— **不可叠加**,三个杠杆都在动同一段光路的 SNR;300 m 处 OM4 15.7 GHz 模式带宽是墙。
  (2026-10-03 统计引擎一致性修复后第二次重跑的数;第一次重跑 157 / 254 / 211 m、杠杆 99 m 起 +81 / +107 / +132 / +188 m、之和 +320 m;
  更早 143 / 249 / 182 m,杠杆 97 m 起 +62 / +81 / +132 / +185 m、之和 +274 m。结论不变。)
- 两个工程坑:(1) 零长度"理想"电段在 2×baud 网格上是砖墙,补零到 dt 后成 sinc,trimmer 按一阶差分能量整段保留(32k 样本),
  再与 CTLE 后的二段冲激直接卷积 —— 理想段改到 1/(2dt) 网格上(不补零、精确 δ);(2) 高斯模式带宽 / 色散响应是零相位,
  反因果的半边绕到数组末尾同样骗过 trimmer —— 光纤块加纯延时(5σ_t / 四分之一衰落周期),幅度、游标、BER 都不变。
  pre-PD 冲激 32760 → 76 样本,重定时一点 177 s → 0.7 s。Butterworth O/E 在 425 GHz 处还有 4e-3,其段冲激仍整段保留,
  但另一半短了之后卷积不再是瓶颈。
- 验收:三段各自 BER ~1e-3 / ~1e-2 时端到端在自身 Wilson 区间(z = 3)内等于 1 − ∏(1 − pᵢ),两种架构都过;
  重定时的光路段 BER < 同光路同电段的 LPO 整链(方向断言);统计级联 / 时域端到端 2× 内。



### 8. 大信号曲线与 TDECQ(阶段 3)

**曲线**(`optical/eo.py::StaticCurve`,`li_compression` = 1 − 小端斜率/大端斜率):VCSEL 二阶 L-I 带热翻转
P = u + κ(1 − u²),κ = c/(2(2 − c)),R_LM = 1 − 8κ/3(闭式,测试钉住);EML 指数 EAM 吸收
P = 2(e^{γ(u+1)/2} − 1)/(e^γ − 1) − 1,γ = −ln(1 − c)。两端外电平钉在 ±1,OMA / ER 不变;零光功率下限,翻转峰后保持。
来源:Coldren《Diode Lasers and PICs》ch.2 / ch.8 的教科书形状,approximate, unsourced to a clause —— 802.3 只通过
R_LM(120D.3.1.2)和 TDECQ 约束它的结果。

- **曲线位置 = Wiener 顺序(E/O 小信号输出之后)**,两种器件都这样。EAM 物理上就是这个顺序;VCSEL 物理上 L-I 在弛豫
  动态之前(Hammerstein),对调只改变曲线怎么弯 ISI,不改变稳态电平。初稿按物理分开放,VCSEL 的驱动段只剩段 A,
  短/理想电段在 2×baud 网格上是砖墙(见 pitfalls),TDECQ 读成 23 dB —— 被推翻,见下节。
- **接收机电平**:`_levels(cfg)` 在曲线开启时返回曲线后的电平(ADC DSP 自适应参考电平的行为);TX 仍发驱动器电平。
  统计引擎用同样的电平但链路线性,并 warning;实测 ADC PAM4 统计/时域 0.61–0.70(c = 0…0.3),仍在 2× 内,但不作保证。
  (2026-10-08 更正:统计引擎现在建了曲线对 ISI 的弯折,warning 只剩显式传 `level_sigma` 时;见下方「统计引擎里的曲线」。)
- 曲线关闭时三段路径不启用,475 值指纹(含光链路预置)与 main 逐位相同;强制用恒等曲线走三段路径,与两段路径的错误数
  在 Poisson 误差内、SNR 差 < 0.3 dB(测试)。

500 m SMF,OMA −8 dBm)、VCSEL mixed-signal NRZ(OMA −16 dBm)—— 各扫 c = 0…0.5,80 万符号,统计用时域训练出的 FFE:

|---|---|---|---|---|---|---|
| VCSEL ADC ER 4.5,只用稳态电平 → 加图样平移 | 0.99 | 1.04 → 0.98 | 1.07 → 0.95 | 0.98 → 0.94 | 0.86 → 0.93 | 0.71 → 0.88 |
| VCSEL ADC ER 6 | 0.94 | 1.14 → 1.01 | 1.16 → 0.96 | 1.02 → 0.94 | 0.87 → 0.94 | 0.64 → 0.86 |

- **为什么只用稳态电平不够**:曲线在 E/O 动态之后(Wiener),它弯的波形已经带着邻符号的 ISI。NRZ 尤其明显 —— 曲线把两个外电平
  钉在 ±1,稳态电平完全不变,统计 BER 对 c 不动,而时域 BER 涨了 2.4×。
- **拆解**(c = 0.4,无噪声的曲线链路减线性模型,按图样取条件均值):残差 std 是内眼半间距的 0.12–0.13(ADC)/ 0.03(NRZ);
  按当前符号分组剩 0.095–0.11(NRZ 0.03),再按两个最近邻分组剩 0.005–0.04 —— 当前符号 + 两个最近邻解释 92–96 % 的方差。这正是光噪声
  已有的分箱(`slicer_sigma_binned`)。
- **模型**(`optical_stage.curve_pattern_offsets`):每个相位、每个(电平, 下一符号, 上一符号)箱,箱内残差的均值作为平移、
  方差并进该箱的噪声。平均在配置的码型上做(PRBS13(Q) 三个周期,时域引擎发的就是它),无噪声、同一组冲激、同一个曲线调用 ——
  是对该码型的精确平均,不是 BER Monte Carlo。接收机判决电平是固定的(曲线像电平 × 主光标,不自适应),所以平移加在信号上、
  门限不动,与时域一致。
- 曲线关闭时不走这段:804 值指纹与 main 逐位相同。测试 `tests/test_optical.py`(EML ADC 与 MS NRZ 在 c = 0.4 的 1.5×、
  恒等曲线下修正为 0、平移随邻符号变)。
- **口径**:光噪声的方差仍按线性的光功率算(曲线也弯了功率,未建);MS 的 DFE 在统计引擎里是理想抽头,时域是自适应的 ——
  曲线让上一个符号的贡献不再严格线性,DFE 能吸收的那部分两边处理不同,NRZ 那行 0.91–1.04 说明这里影响不大。

## 被推翻的判断

- **"OM4 100 m 的 3 dB 点 = 47 GHz"**(计划措辞)→ 47 GHz 是 −3 dBo(\|H\| = 0.5),电 −6 dB。
  代码按物理定义实现,测试断言 \|H(47 GHz)\| = 0.5 且 `loss_at` = −6.02 dB。按计划措辞实现会把光纤带宽高估 1.4×。
- **"噪声注入在 O/E 之后、seg_b 之前"** → 注入在光电二极管电流节点(O/E 之前),理由见 §2。
- **"统计引擎每电平用名义功率的 σ"** → 二阶矩版(§3),名义版在 ER 6 dB 悲观 2×。
- **"σ 对了 BER 就对了"** → 不对:尺度混合的尾部比匹配方差的高斯重,这是剩余 0.55–0.63 的来源。(2026-10-03:按邻符号分箱后 0.94–0.99,见 §3 更新。)
- **"VCSEL 的 L-I 曲线放在 E/O 动态之前(Hammerstein)"**(阶段 3 初稿)→ 两种器件都放在 E/O 小信号输出之后(Wiener)。
  初稿让段 A 单独卷积在曲线之前,理想段在 2×baud 网格上是砖墙,零相位 sinc 绕回把 ~2000 UI 前的符号混进驱动,
  c = 0.2 的 TDECQ 读成 23 dB、OMA 少 28%;改后同点 2.28 dB。对 VCSEL 是近似(只改 ISI 的弯法,不改稳态电平)。
