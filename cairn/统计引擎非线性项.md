> 假设清单本身在 `engine/statistical.py` 顶部(新增近似往那儿补),这里放数据与取舍。

## 2. TI lane 失配:白噪声,对抽取求系综

`stat_noise.ti_mismatch_sigma`:ADC 输入处加 σ_o² + σ_g²·E[x²] + (σ_s·T)²·E[ẋ²],与量化噪声同一节点(FFE 输入),
E[x²] / E[ẋ²] 取主游标相位上随机数据的值(`adc_input_moments`)。

- 每条 lane 的误差其实是固定的(每 n_lanes 个样本同一个 offset / gain,一条链路只抽一次),一次抽取在判决器上是 n_lanes 个平移的混合;
  白噪声是**对抽取的系综**,时域按种子散布在它周围。σ 大时偏悲观(5 mV 1.45×):混合的尾巴比等方差高斯短。
  (更正 2026-11-05:5 mV 的 1.45× 是 6 个种子的抽签,32 个种子 1.07×(§1 末);偏悲观在三项一起的预设上还在,128 个种子 1.34×。)
  (更正 2026-11-05 晚:"混合的尾巴比等方差高斯短"不对 —— 对单次判决,高斯平移对抽取求平均正好是和高斯卷积,白噪声模型是精确的;预设上的 1.34× 另有来源,见 §6。)
- 只建 `cal.mode: off`:`calibrated` 归零 offset / gain;后台环路 `mu_skew` > 0 去掉 skew;后台 / 前台的估计残差**不建**(按校准干净算)。
- skew 用 dp/dt 的一阶近似;0.05 UI 内 1.06×。

## 3. 削顶与驱动非线性:只警告

- 削顶的误差是稀疏的大冲击、集中在极端码型上,不是白噪声;按方差加进去没有根据,所以只警告:
  ADC 输入最坏峰值 Σ|p_k|·max|a| 超过半满量程时 warning(铁律 3 范围外)。224G 预设最坏峰值 0.19 V:半满量程 0.175 V 时域还 0 错、0.125 V 起误码,
  所以警告偏早(峰值是全部游标同号的上界),不会漏。
- `tx.drv_nl` 原就 warning;摸底量了离多远(上表),压缩到 P1dB 0.6 V 已 4×。要建的话得像光侧 curve 那样按近邻码型分箱
  (`optical_stage.curve_pattern_offsets`),目前没有实际需求,不做。

## 4. 没摸的

- PR 对 LMS / CDR 的反作用(ROADMAP #12 ⑤ 的第三项)没量。(更正 2026-11-03:§15 早量过;这次补了 NRZ 的阈值与 PAM4 原始样本 MM 的警告,`cairn/DSP发端与PR.md` §44。)
- 统计引擎的环路噪声(`stat_loop` 的 `noise_var`)与时域的 DFE 起点仍只取量化噪声,不含失配。
  (2026-11-03 晚核过,不改:那两处是 MMSE 的正则项。`PAM4 224G ADC (TI mismatch)` 预设上失配 6.18 mV、热噪 + 量化 2.4 mV,时域 LMS 收敛的 FFE 离现在的启动解只差 0.7 %,
  把失配方差加进去启动解反而离开 29 %(统计读数 1.26e-3 → 9.1e-4,往时域靠但靠的不是时域收敛到的抽头)。固定的 lane 失配对 LMS 不起白噪声那样的正则作用。)

## 5. 一次抽取不代表链路

同一个 TI 失配预设,8 个种子 × 20 万码元,每个种子的时域 BER:7.7e-6 / 0 / 1.6e-3 / 1.2e-4 / 0 / 1.0e-2 / 4.4e-3 / 0 —— 跨四个数量级以上(失配每条链路抽一次)。
合起来 2.0e-3,统计 1.25e-3(0.61×);只取前 3 个种子读 2.33×,是抽签。统计引擎给的是对抽取的系综均值,对单个种子的中位数会差一个数量级以上。
对照失配链路时,时域要多种子合起来数,或者把失配当工艺角(`calibrated` / 固定种子)单独看。

更正 2026-11-05:上面这组数是旧抽法下的。lane 失配与比较器失调当时接在发端抖动、接收噪声之后从主流抽,噪声个数随 `n_symbols` 变,
所以同一个种子在 4 万码元与 20 万码元是两颗芯片(种子 5:1.6e-3 对 0 错;种子 6:1.8e-4 对 1.0e-2)。现在每链路的抽取用
`[sim.seed, tag]` 的独立流(`engine.timedomain.per_link_rng`),同一种子在任何码元数下同一颗芯片(种子 3 / 5 / 6 在两种码元数下
3.4e-4 / 3.6e-4、0 / 0、0 / 1.8e-5)。重量:8 个种子 × 20 万码元 5.2e-6 / 1.1e-3 / 3.6e-4 / 2.1e-3 / 0 / 1.8e-5 / 2.8e-5 / 3.6e-4,
合起来 4.96e-4,统计 1.25e-3(2.52×);128 个种子 × 4 万码元合起来 9.36e-4(1.34×),34 个种子 0 错、中位数 1.2e-4、最大 1.3e-2。
8 个种子的池子是 128 个合起来的 0.19–2.0×(10–90 %,中位 0.81):旧的 0.61× 和新的 2.52× 都在抽签范围里。
结论不变 —— 统计引擎读的是对抽取的平均,对照要几十个种子;GUI 的 Draw spread 页(8 个种子)只能看散布,不能当系综。

## 6. 预设 1.34× 的来源:DFE 误码传播遇上固定平移(2026-11-05)

`PAM4 224G ADC (TI mismatch)`(offset 6 mV、gain 2 %、skew 0.015 UI、热噪 1.5 mV),每格 `seed_spread` × 4 万码元,括号是对种子 bootstrap 的 10–90 %:

| 设置 | 种子 | stat / 合起来的时域 |
|---|---|---|
| 预设(三项) | 512 | 1.35(1.17–1.59) |
| 只 offset 6 mV | 512 | 1.35(1.14–1.63) |
| 只 offset,FFE 冻结 / FFE + DFE 都冻结(不自适应) | 512 | 1.34 / 1.34 |

gain 2 % 单项 64 个种子 0 错 —— 1.34× 全在 offset。拆开:
- **统计引擎加方差的方式是对的**:时域里关掉 offset、在 ADC 噪声上按平方和加 6 mV 白噪声(同一节点),时域 9.35e-4 对统计 9.90e-4,1.06×。
- **逐相位平移与模型一致**:判决器上按 lane 相位的平均误差 = Σ w_k o_(m−k)(相关 0.999–1.000、斜率 0.97–1.01,4 个种子),σ_d ≈ σ_o‖w‖ ≈ 4 mV。
  所以对单次判决,"固定平移对芯片求平均"与"白噪声"是同一个分布,§2 的"混合尾巴短"站不住。
- **差在跨符号的动态**(同一配置下"白噪声 / 固定 offset 的芯片",256 个种子):照常 1.27;CDR 冻结 1.20(0.98–1.53);DFE 关 1.07(0.90–1.30);两个都关 1.06。
  开着 DFE 的那部分缺口最大:固定平移让误码集中在少数几个相位上,DFE 误码传播的条件跟白噪声时不同(机理未拆;一个候选是 d_m 与 d_(m+1) 经 FFE 自相关负相关)。
- 取舍:**不建**。1.3× 在铁律 3 的 2× 内、方向偏悲观;要建得按每个相位的平移给 DFE 误码链做条件,还要对芯片求平均 —— 代价大,收益是把 1.3 拉到 1。
  对照失配链路的数仍按 §5:几十个种子合起来数。
