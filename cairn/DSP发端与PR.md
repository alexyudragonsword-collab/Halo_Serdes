## 2. DAC(`tx/dac.py::TxDac`)

- **约定**:`dac_fs` 是**峰峰值**(与 `tx.swing`、`adc.fullscale` 一致),h = fs/2,LSB = fs/2^N,码 c → −h + (c + ½)LSB(中升)。
  默认 fs = swing·Σ|taps|,即 FFE 输出的峰峰值,按构造不削峰。|x| > h(1 + 1e-9) 计削峰 —— 容差是因为 backchannel 训到
  恰好填满满量程时,舍入会让一部分值超出 1e-16。
- **INL**:2^N − 1 个单元,低 N−m 位二进制成组、高 m 位 2^m − 1 个温度计元件,每单元 1 + e、e ~ N(0, σ_unit)。端点修正后
  Var(INL_c) = σ²c(1 − c/M),**与分段无关**(分段决定 DNL / 单调性:全温度计单调,纯二进制在 σ 0.3 时会非单调,测试钉住);
  码平均 E[INL²] = σ²(M − 1)/6(测试 60 种子 ±20%,逐码方差剖面 ±25%)。
- **失配用独立随机流** `default_rng([seed, 0x7DAC])`,不吃链路的 rng:失配是芯片属性,开 DAC 不能挪动后面的边沿 / 噪声 / ADC 抽样
  (测试:剖面时钟下有无 DAC 的边沿逐字节相同)。
- **SQNR 闭式**:6.02N + 1.76 假设误差在一个 LSB 内均匀。正弦大部分时间在峰值附近,所以**单一幅度**的结果取决于峰值落在顶码的
  哪个位置:理想 5 bit 恰好满幅读 31.48 dB,低 ¼ LSB 读 32.07(闭式 31.86),N = 5..8 恰好满幅都偏低 0.13–0.38 dB。
  `sqnr_of_sine` 对 16 个峰值依次走过顶码一个 LSB 的幅度取误差功率平均(对满幅信号功率),这正是闭式描述的条件:
  N = 3..10 与闭式差 ≤ 0.09 dB。量化器本身用均匀输入核过(误差功率 / (LSB²/12) = 1.000 ± 0.002)。

### 统计引擎的等效噪声

σ_q² = LSB²/12 + E[INL²]·LSB²,作为**每 UI 白噪**加在 DAC 输出,经 DAC → 判决器的符号响应(信道 × CTLE × VGA × RX FFE,
**不含** TX FFE,因为误差在 FFE 之后)的全部游标平方和到判决器:σ_rx = σ_q √Σp_k²,与 RX 噪声功率相加。
`dac_noise_at_slicer` 与"有无 DAC 两条波形之差在判决时刻的 RMS"对得上 15% 以内(5 / 7 bit,FFE 开)。

近似的边界:误差其实是 DAC 输入的确定函数。FFE 把输入摊到很多码上时像白噪;**没有 TX FFE 时 PAM4 四个电平落在四个固定码上**,
"噪声"其实是固定的电平偏移,统计引擎把它平均成高斯。实测这种最不利情形下铁律 3 仍过(下表),但比值随位数下降
(4 bit 0.73–0.81,6 bit 0.94–0.95)—— 位数更少时偏移更像确定性误差。

**铁律 3(只开 DAC 量化,静态引擎 vs 统计引擎,32 GBd PAM4,无 TX FFE,RX FFE 2+6、DFE 2)**:

| 损耗 @16 GHz | 噪声 | 4 bit 比值 | 5 bit | 6 bit | 4 bit 时 DAC 把 BER 抬了 |
|---|---|---|---|---|---|
| 6.4 dB | 0.030 | 0.81 | 0.89 | 0.95 | 2.73e-2 → 3.65e-2 |
| 10.7 dB | 0.020 | 0.77 | 0.87 | 0.94 | 1.99e-2 → 2.81e-2 |
| 15.0 dB | 0.012 | 0.73 | 0.85 | 0.94 | 9.48e-3 → 1.52e-2 |

为什么不带 TX FFE 测:见 §5,静态引擎看不见 TX FFE,带 FFE 的 BER 对照不可信;σ_q 的折算本身用上面的波形差 RMS 单独钉住。

## 3. 驱动器(`tx/driver.py`)与 E/O 共用压缩参数

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 35 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

- `StaticCurve` 从 `optical/eo.py` 提到 `core/static_curve.py`(`tx/` 与 `optical/` 互不 import,`core` 两边都能用),`optical/eo.py`
  重导出,光侧行为不变(TX 路径指纹含 c = 0.3 的光发射功率,逐位相同)。`rlm()` 一起搬。
- `drv_nl = "curve"` 用 **rollover** 形(凹,压顶电平),满量程 = DAC 满量程的一半(默认 swing·Σ|taps|/2),所以同 c、同归一化输入
  时驱动器与 VCSEL 曲线**逐位相同**(测试)。它是单端 / 一侧余量不够的驱动器;对称的差分级用 `tanh`(按单音 1 dB 压缩点定尺度,
  比值 A_1dB / V 由二分法解出,测得增益 −1.00 ± 0.02 dB)或 `cubic`(c₃ = 4/(3 OIP3²),输入钳在增益峰 1/√(3c₃);HD3 闭式
  c₃A³/4 ÷ (A − ¾c₃A³),实测差 < 1e-13 dB)。
- **Hammerstein**:曲线作用在 ZOH 后的波形上、单极点之前(测试逐字节钉住顺序)。光拓扑下驱动器先压、E/O(Wiener)再压。
- PAM4 测得 R_LM 随 c 单调降:理想 DAC、无带宽时 c = 0 / 0.1 / 0.2 / 0.3 → 1.000 / 0.940 / 0.874 / 0.801(示例 35)。
- 统计引擎不建驱动器非线性,`drv_nl != "none"` 时 warning(铁律 3 范围外)。接收端判决电平**不**跟随驱动器曲线(光侧阶段 3
  让 `_levels` 跟随 E/O 曲线;驱动器这里没做,压缩的代价因此全额落在固定电平的接收端上 —— 示例 35 的 reach 是这个口径)。

## 5. 既有缺口:接收端的起始均衡看不见 TX FFE

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 18 / 31 / 32 / 35 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

静态引擎从**不含 TX FIR** 的信道脉冲解 RX FFE、取相位、算 DFE 和电平尺度,而它均衡的波形含 TX FIR;时域引擎两种架构的起始

## 8. 发端 1 + aD(阶段 3,2026-10-03)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 18 / 37 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**接口**:`PrConfig(target=(1.0, a), at="tx")`。`TxPipeline.pr_filter` 在电平之后、FFE / DAC 之前做 (x_k + a·x_{k−1}) / (1 + a);
`equivalent_symbol_response` 把它并进去(两个引擎的脉冲分析都看得见),收端用与 §7 相同的 1 + aD 检测。**峰值归一**是有意的:
发端的约束是 DAC / 驱动器的满量程,合成电平多出来的那份从电平间距里出(a = 1 时间距减半)。不设 `at="tx"` 时逐位同 main(488 + 44 值)。

**主光标定位(坑)**:1 + aD 脉冲有两个可比的光标(a = 1 时等高),取 argmax 会落在 a·x_{k−1} 那个上,收端整体错一个 UI。

PR 开启且前一个 UI 的样本 ≥ 峰值一半时取前一个。

**示例 37**(示例 18 的接收端,memory-2 Viterbi,40 万符号):

**为什么**:线性链路、噪声在收端。收端 FFE 要把"信道 ⊛ 发端 PR"均衡到 [1, a],等价于把信道均衡到 delta —— 与无 PR 时同一个

峰值代价。收端 PR 的收益恰恰来自"FFE 少反演一点",这在发端做不到。理想 ADC 下把发端摆幅放大 (1 + a) 倍(不限峰值)时,

对照做不干净 —— 摆幅放大要求 ADC 满量程同比放大,ENOB 噪声跟着放大。

**判断**:在本模型的 224G 电链路上,发端 PR 不值得做;收端 PR(§7)是 PR 的正确位置。发端 PR 可能占优的条件本模型没有:
噪声 / 串扰在发端带宽限制之前进入、或发端器件本身带宽受限且噪声在其后(光调制器 duobinary 的场景)。口径:a 固定、memory-2、
无 DAC 量化(加 DAC 后发端 PR 的间距更小,只会更差)。
(2026-10-11 更新:光调制器的场景量过了,两种噪声位置下发端 PR 都不占优,见 §16。)

**统计引擎缺口**:发端 a = 0.5 时比时域悲观 2.5–2.9×(FFE 输出 ρ1 ≈ −0.67,长度 2–6 的交替事件距离 1.10–1.20 几乎相同,union bound
重复计嵌套事件);发端 a = 1 预编码 1.2–1.5×。

**更正(2026-10-04,已修)**:`pr_error_events(snr=)` 对 L ≥ 2 的事件只计"与前一事件不重叠"的那部分,
P(A_L 且非 A_{L−1}) / P(A_L) 由两事件统计量的二元正态(Owen T)给出 —— Hunter 界的链式形式,仍是并集的上界,重叠只按 AWGN

收端 a = 1 预编码 1.28–1.34×(BER 7e-5…6e-3;收端 a = 0.5 在 6e-3 处此前 2.34×)。发端 a = 0.5 进了不变量 3 测试。

## 9. a 由收端自己选(`pr.adapt`,2026-10-04)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 36 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

## 11. 统计引擎的逐符号判决(2026-10-05,原 ROADMAP P3 #8 余项)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 18 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:内核给 LMS / CDR(无序列检测器时就是检测器本身)的逐符号判决是"样本 − a·x̂ₖ₋₁ − b·x̂ₖ₋₂ 再切",错判会传下去;
统计引擎原按理想抽头(只把受控光标移出 ISI)算。`mlsd: none`、示例 18 信道 −0.24 m、`enob=None`、2.2 mV:时域 / 统计
a = 0.5 2.66×、0.75 2.98×、1 4.09×、1 预编码 1.21×(都偏乐观)。

**模型**(`pr_symbol_decisions`):状态 = 最近一或两个判决误差(电平步数,PAM4 7 或 49 个状态);下一误差的分布 = 各电平的

## 14. 统计引擎的 PR 联合界:整族事件取并集(2026-10-10,ROADMAP P2 #15)

**问题**:§13 量到手选 c < 0 的四光标目标统计偏悲观到 2.09×(铁律 3 越界)。时域的误码事件几乎全是长度 2–10 的交替事件,
联合界里这些长度的距离挤在 1.22–1.32。原做法(2026-10-04)对每个长度 L 只扣掉它与 L − 1 的重叠(Hunter 链式上界)。

**两层多算**:①同一起点上,长度 L 不只与 L − 1 重叠,距离这么平时与所有长度都重叠;②长度 4 的错误 (+, −, +, −) 包含了从下一个
符号起、符号相反的长度 3 事件 (−, +, −),逐起点求和会从下一个起点再算一次。离线原型只做①:2.09 → 1.88×、(1, 0.8, 0.1, −0.25)
1.75 → 1.60×;①②都做:2.09 → 1.31×、1.75 → 1.10×。

**做法**(`pr_error_events(snr=...)`):竞争集合是全部事件 —— 每个长度、两族(交替 / 同号)、每个能重叠的起点(±11 个符号,
两种符号)。检测器选比正确路径度量优势最大的那条:度量差 2σ s_i (Z_i − t_i)。每个起点 0 的事件 j:在 j 的度量条件成立
(Z_j > t_j,从正态尾部抽)与 j 的每步移动在符号上可能(符号均匀,条件在 j 的移动上)的前提下抽样,权重 = 支持率_j ×
mean(errs(选中) / 同时成立且符号允许的事件数)。于是 Σ_j P(A_j) w_j 是每个起点的判决误码期望 —— 并集而不是和
(Owen、Maximov、Chertkov 2019 的 at-least-one-event 估计器,事件再稀有相对误差也有界)。条件下概率 < 1e-6 的事件剪掉;
每事件 1000 个样本,种子固定(确定性)。只在接收机采样的相位算一次,按与简单求和的比值用到其他相位(逐相位算的原型
差 1–2%)。每次统计调用多约 0.1 s(0.38 → 0.50 s)。

**核对**:中等 SNR(1.6,max_len 6)下对整族直接抽样(20 万样本,不经重要性抽样):并集 / 直接 0.98–0.99,简单求和是它的 2.1–4.1 倍
(`tests/test_mlsd_fec.py`)。孤立事件(白噪声、近 delta 目标的单错)权重不变。

## 15. 高 SER 下 CDR 失效:统计引擎报"环路负载"并警告(2026-10-10,ROADMAP P2 #15 余项)

**问题**:§13 量到强目标 (1, 1.4, 1.0, 0.4) 在 3 mV 下时域 BER 0.16、统计 3e-3。统计引擎写明不建逐符号判决对 LMS / CDR 的影响。

## 16. 光 duobinary:带宽受限的调制器上 PR 放哪(2026-10-11,原 ROADMAP P3 #8 余项)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 32 / 40 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§8 的判断里留了"发端 PR 可能占优的条件本模型没有":发端器件本身带宽受限(光调制器的 duobinary),噪声在其前或其后。
收端噪声那一半(RIN、PD / TIA)光链路本来就有;发端那一半没有 —— 先加了 `tx.noise_rms`(DAC 输出处每 UI 一个白噪声,独立
随机流 `[sim.seed, 0x7E5]`,关着逐位不变,819 值指纹)。

**预判(线性高斯 + MMSE FFE + 序列检测)**:
- 噪声在带宽限制**之后**:收端 FFE 只需把信道均衡到 1 + aD,少反演、少放大噪声,收端 PR 赚;发端 PR 的收端仍要均衡到 delta
  (§8),还付峰值 —— 比不做还差。
- 噪声在带宽限制**之前**:噪声与信号走同一条链,到判决器同形;带宽限制本身几乎不扣分,任何 PR 都没有噪声放大可省。收端 PR 反而
  把噪声染成目标的形状(1 + D 时 ρ1 = +0.5),欧氏度量的 Viterbi 不再最优(单错事件的有效距离约少 1.8 dB);发端 PR 的判决器
  噪声是白的,Viterbi 收回 10·log10(1 + a²) 的距离,但峰值归一付 20·log10(1 + a)。
- "光 duobinary"的实际做法是让调制器自身的低通当 1 + D 滤波器、发端只做预编码 —— 在本框架里就是**收端 PR(a = 1)+ 预编码**,
  不是发端数字整形。
基带原型(纯 numpy:单极点信道、最小二乘 FFE、库里的 Viterbi)先核过排序:发端噪声时无 PR 最好、收端 PR 小亏、发端 PR 最差;
收端噪声时收端 PR 最好、发端 PR 最差。

  仍多要 1.7–2.1 GHz。发端整形与预加重方向相反:前者添 ISI,后者去 ISI。

它付得最多。光 duobinary 的收益在本框架里由收端 PR(a ≈ 1,配预编码时逐符号判决不传播)拿到,发端该做的是预加重。口径:IM/DD

## 17. MMSE 起始解计入发端噪声(2026-10-11)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 40 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§16 量到 `pr.adapt: mmse` 在发端噪声为主时选错目标。起始解(`mmse_pr_target` 与起始 `mmse_ffe`)把噪声当作 FFE 输入处的
白噪声(收端 + ADC),而发端噪声到 FFE 时带着整条链的颜色、与信号同形 —— 这时 MSE ≈ Pσ²/(P + σ²)·|d|²,首一目标 |d|² = 1 + a²,
正确答案是 delta。旧解只看见 ISI 的形状,在示例 40 的 12 GHz 链路上选 a = 0.98、22 GHz 选 0.26(发端噪声 40 mV)。

**`adapt: lms` 不会自己走回来**:同样的点 20 万符号后 0.980 → 0.981、0.259 → 0.258;BER 与 `mmse` 几乎相同(5.65e-4 对 5.47e-4)。
代价面在 a 这一维很平,按现有步长 LMS 几乎不动 —— 起始解定了结果。

**做法**:`mmse_ffe` / `mmse_pr_target` 加可选的 `noise_cov`(n_taps × n_taps,与 `noise_var` 同一尺度),时域 ADC 收端与静态引擎的
起始求解传入发端那份:σ²(`tx.noise_rms`)× DAC → FFE 输入逐 UI 响应的自相关(Toeplitz,`statistical.tx_noise_covariance`)。
DAC 的量化有意不计入(有界、不是高斯,§16 的坑;带 DAC 的链路起始解照旧);没有 `tx.noise_rms` 时逐位不变(819 值指纹)。

**结果**(示例 40,发端噪声为主):MMSE 选 a ≈ 0.001(12 GHz)/ 0(22 GHz),LMS 同;容忍的发端噪声 42.8 / 48.2 mV,与对照
(42.7 / 48.2)相同,此前 36.7 / 45.6(2026-10-12 网格改在实际采样点拟合后 42.7 / 48.2 对对照 42.7 / 48.1);同为 40 mV 时 12 GHz 的 BER 5.5e-4 → 1.0e-4。噪声在调制器后的那几列不变(没有发端噪声)。
测试:噪声全与信号同形时 MMSE 目标是 delta、同功率的白噪声选 a > 0.3;协方差的形状与对角线。

## 18. 降状态网格(DFSE):PR 目标要几个状态(2026-10-11)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 18 / 38 / 42 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:`cairn/功耗建模.md` 算出全网格的第二个受控光标在 112 GBd 上不现实 —— 256 状态的 Viterbi 只算运算就 12.73 pJ/b,
远超已发表 224G 收端的总量。§12 又量到残余 memory 1 与 2 只差 ≤ 0.03 dB:21 抽头 MMSE FFE 在目标之外几乎不留 ISI。
那么网格可能只需要目标本身的受控光标。

**做法**:`rx.mlsd.state_memory` = K(decision-feedback sequence estimation,Duel-Hallen & Heegard 1989)。网格跨
L = len(pr.target) − 1 + memory 个光标,状态只记最近 K 个符号(N^K 个),其余 L − K 个光标用每条幸存路径自己尾部寄存器里的
判决减掉;加比选时连同尾部一起继承。状态打包、加比选顺序、回溯与全网格相同,所以 K = L 时逐判决相同(测试),不设时仍走原内核。
统计引擎:降状态网格里两条路径在最后一个错误之后 K 个符号合并,比较到此为止 —— 长 n 的错误事件只计 h * e 的前 n + K 个样本
(`mlse_min_distance_sq` / `pr_error_events` 的 `state_memory`);幸存路径反馈出错的传播不计。首版定点模式只支持全网格(配置拒绝
K < L):bit-true 检测器把全网格做成期望值表,没有逐路径反馈;SV 同。(同日已补,见本节末"定点与 RTL"。)

## 19. 统计引擎的 PR 联合界:残余 ISI 按事件投影(2026-10-11,ROADMAP P2 #16)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 40 / 42 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§18 量短 FFE 时发现统计引擎在 PR 目标 + 3–7 抽头 FFE 上悲观 1.8–10.7×(铁律 3 越界);同样的 FFE 配 delta 目标
0.88–1.62,21 抽头配 PR 目标 1.01–1.10。

**原因**:联合界里每个事件按"噪声除以 g、网格外的残余 ISI 原样"算概率 —— 等于把 ISI 相对门限放大了 g 倍。检测器在

## 20. 光链路上联合界的 SNR:光噪声计入(2026-10-12,ROADMAP P2 #18)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 40 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§19 量到光链路(示例 40 的 VCSEL + 100 m OM4)上发端 PR、噪声在调制器之后时统计偏悲观:a = 0.5 无主机 FFE f_r 16 / 17 GHz
2.99 / 2.28×,a = 1 预编码 17.5 GHz 1.73,带主机 FFE 11 GHz 1.50;同链路对照 0.91,收端 PR 1.01–1.45。

**排除**:①光噪声核本身 —— 关掉光噪声(RIN −200 dB/Hz、TIA ≈ 0)只留接收端电噪声 4.5 mV,发端 PR a = 0.5 17 GHz 1.02×(289 个误码),
所以不是光链路的信道或发端 PR 的电平;②残余 ISI 与分箱邻符号的平移 —— 锁定相位上残余 rms / 主光标 0.0007、两个分箱邻符号的光标 0。
③光噪声在 FFE 前已被 TIA / CTLE 着色:ρ1 −0.60 对只看 FFE 抽头的 −0.55,差得太少,不够解释 3 倍。

**原因**:联合界的重叠权重(§14,`pr_error_events(snr=...)`)按 `half_gap / noise_sigma` 的 SNR 抽样,而光链路的 `noise_sigma` 只有
接收端电噪声(这条链路 0.08 mV),光噪声在逐电平 / 分箱的核里(1.7–3.2 mV)。SNR 被高估了几十倍,事件看起来互不相交,并集退化成
简单求和 —— §14 量过简单求和在发端 a = 0.5(各长度距离挤在一起)上悲观 2.5–2.9×,正是这里的量级。收端 PR 的距离不那么平,吃亏少。

**做法**:抽样的 SNR 用链路的全部噪声 —— 电噪声加光噪声按电平 / 邻符号组合的平均方差(有大信号曲线时加它的方差)。电链路逐位不变
(仓库指纹)。

**结果**(统计 / 时域,示例 40 的链路,40 万符号):

| 链路 | 原 | 现 |
|---|---|---|
| 发端 PR a = 0.5,f_r 16 / 17 GHz(524 / 104 个误码) | 2.99 / 2.28 | 1.40 / 1.36 |
| 发端 PR a = 1 预编码 17.5 GHz / a = 0.5 带主机 FFE 11 GHz | 1.73 / 1.50 | 1.40 / 1.05 |
| 收端 PR a = 1 预编码 11.5 / 11.0 GHz | 1.01 / 1.05 | 0.87 / 0.83 |
| 收端 PR MMSE 11.5 / 11.0 GHz / 带主机 FFE 8 GHz | 1.41 / 1.39 / 1.19 | 1.20 / 1.08 / 0.90 |
| 发端噪声为主(§16 / §17 的情形)| 1.45 | 1.44 |
| 对照(delta + Viterbi) | 0.91 | 不变 |

`tests/test_pr.py` 钉住发端 a = 0.5、16 GHz 一格(旧 SNR 下失败)。2026-10-12 网格拟合后(§21)重量:各格动 ≤ 0.03,范围仍 0.83–1.44。

**未做**(已知近似,方向偏悲观):每个事件的噪声取它第一个符号的电平与邻符号的方差,用于整个事件。光噪声随电平变(这条链路
σ 1.7–3.2 mV),而长 L 的事件跨 L + 1 个样本,真实方差是各样本各自方差的加权平均。离线在锁定相位按随机符号逐样本算的精确混合
让上表再低 0.6–0.8×(发端 a = 0.5 16 GHz 约 1.0、17 GHz 约 0.8);"首样本 + 其余取平均"这种便宜的近似又压过头(0.51–0.84),
两者都没进引擎 —— 现在 0.83–1.44 已在 2× 内。

## 21. Viterbi 的网格在接收机实际采样点拟合(2026-10-12,ROADMAP P2 #17)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 06 / 38 / 42 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§18 量短 FFE 时发现 FFE 只有主抽头(`n_pre = n_post = 0`)时 MLSD 比自己的 slicer 差:示例 42 的链路 0.06 m、delta 目标、
memory 2,MLSD 后 BER 8.5e-3,关 MLSD 1.16e-3(slicer SER 2.32e-3)—— 序列检测多出约 7 倍误码。

**原因**:时域引擎给 Viterbi 的光标取自起始的脉冲模型 —— 脉冲峰值处的游标经最终 FFE 抽头 —— 而环路不停在峰值上。FFE 只有主抽头时

+0.058,模型说 −0.086(符号都反了),主光标只有电平的 0.92。在错的模型上 Viterbi SER 9.2e-3;换成拟合的光标(连主光标增益)为 0,

0.023 / −0.007(Viterbi SER 5.8e-4 → 4.5e-4),21 抽头 ≤ 0.013,Viterbi 三位有效数字相同。另一处:有 DFE 时模型把 DFE 之后的光标
(延迟 n_dfe + 1 …)放到网格的延迟 1、2 上;拟合直接看那两个延迟上有什么。

**做法**(`engine/timedomain._trellis_cursors`,两种收端同一个函数):对判决器样本拟合 y_k ≈ Σ_j c_j L[x_(k−j)],
j = −2 … 网格长度 − 1 + 2,前光标与网格之外的光标一起拟合再丢掉,返回 c_0 … 作为 `post_detect` 的光标向量(主光标增益保留)。
符号按 `score` 的方式跨周跳重对齐。浮点与 bit-true 的 Viterbi / DFSE / sliding 都用它;MLSD 关闭时代码路径不变(仓库指纹逐位不变)。
检测器对信道的了解仍是理想的 —— 之前的脉冲模型同样是仿真器自己的知识,只是读错了地方;统计引擎一直按真实游标算,两边由此一致。
**排除的做法**:对接收机自己的判决拟合(决策导向)。在 slicer 很脏的链路上被判决错误带偏:示例 06(slicer BER 8e-2)的 MLSD 增益
2.4× → 1.4×。按线路符号拟合后示例 06 回到 2.4×(BER +0.5%)。

**结果**:同一 1 抽头链路 MLSD 0 误码(此前 8.5e-3)。12 个用 MLSD 的示例全尺寸重跑,门限附近 reach 动 ≤ 0.1 dB,结论都不变:

## 22. ADC 收端的 DFE:起点决定终点(2026-10-13,ROADMAP P1 #21)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 08 / 19 / 31 / 43 / 45 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**(9c 探针里发现,`cairn/多lane建模.md` §8.4):时域 ADC 收端带 DFE 的四个预设,DFE 抽头全 ≈ 0。FFE 从不计 DFE 的 MMSE
起步(第一后光标也被压到 0),DFE 的初值取自均衡后的游标,也 ≈ 0。

**原因**:联合 FFE/DFE 的 LMS 代价面沿"FFE 留 h1、DFE 消 h1"这个方向是平的 —— FFE 围着 DFE 调,两个方向都不走。`dfe.mu`
放大 3000 倍抽头只动 0.01;同一链路三种起点终点三种(DFE 0.32 / 0.56 / 0.64,BER 2.2e-5 / 3.8e-6 / 1.8e-5)。起初以为是 DFE 步长
没按电平功率归一(§8.4 的说法),已更正。**起点是模型的一部分**,要写清楚。

**做法**:
- `dsp/ffe.mmse_ffe(..., free_post=n)`:主光标之后的 n 个后光标不计入 MMSE 代价(DFE 消它们),其余照旧。
- 时域 ADC 收端(`timedomain` 的起点)`free_post = rx.dfe.n_taps`,正则项的噪声在有 DFE 时加 ADC 噪声
  (`statistical.adc_noise_sigma`;FFE 看到的噪声本来含它)。没有 DFE 时起点不变 —— 那时 LMS 从哪起步都到同一点 ——
  对应的指纹逐位不变。
- **例外**:预编码 1 + D 的复合判决(`pr` 1 + D、`precode`、`adapt = none`)。那个模式下 DFE 反馈的是由复合判决递推重建的线符号,
  错一个就一直错;DFE 用上后一条测试链路 246 → 5779 个误码。它的起点保持不计 DFE。
- `engine.cascade.initial_ffe_taps`(统计单跑的代用解、`lane_curve` 的 ADC 用法)同一规则。
- 统计引擎加 DFE 误码传播(第一个抽头):一次错判在下一个样本上留下 h1 × 电平间距;p = 输入按这个量偏移后的 SER(对下一个
  符号的电平与符号取平均),误码按两状态链 s / (1 − p + s)(`extras['dfe_ep_factor']`;PR / MLSD 路径不加)。理想 DFE 在抽头
  0.57 时比时域乐观 1.8–2.9×、抽头 ≥ 0.69 时 3.3–5.0×;先试的 1 / (1 − p) 在闭眼上发散,两状态链在 s 大时自己封顶。

**结果**(各预设自身噪声):224G 106 GBd 2.27e-4 → 4.0e-6(452 → 8 个误码),112 GBd stress 5 → 0,deep-LR DFE8 3 → 0;1.5 mV
时 6.6e-4 → 4.1e-5。指纹 136 个值变:ADC + DFE 的时域与统计、合成的 adc_dsp / optical 统计(误码传播),以及各带 DFE 收端的
新 `dfe_ep_factor` 键;混合信号的 BER 只在高 BER 处被误码传播抬高(NRZ 32G static 的统计 0.069 → 0.096,PAM4 32G 第 10 位)。
示例全尺寸重跑,13 个输出变(05 07 08 15 16 19 20 21 31 39 43 44 45),38 / 42 不变。**结论变了的**:
- 深 LR 阶梯(示例 19–21):31 → 33 → 36.3 / 38.5 → 42.8 dB 变为 31 → 36.0 → 40.5 / 44.2 → 47.8 dB。DSP 深度 +1.8 → +4.7 dB,
  "深 LR 主要 SNR 受限、DSP 深度收益小"不再成立,与收端 PR 的 +5.0 dB 相差无几(每 dB 0.46 vs 0.48 pJ/b);FEC 与 ADC 两杠杆
  合起来比之和少 0.9 dB(此前多 1.1 dB):ENOB 7.5 的 BER 曲线更陡,内码的 31 倍在它上面只走 3.6 dB。`docs/SUMMARY.md` §04。

## 25. MM 环路模型:检测器读 DFE 之后,噪声按低频谱密度(2026-10-14,ROADMAP P2 #24)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 31 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:剖面时钟下统计引擎的 ADC 收端 MM 环路模型(`cdr/linear.py`),在 #21 让 DFE 起作用后两端读高:示例 31 kp_shift 4 处 1.34–1.39×、
9 处 1.26×,kp_shift 9 处统计 BER 比时域高 5–8×。

**定位(两处,各自独立)**:
- **增益**:内核的检测器读切片器输入(FFE 输出减 DFE 反馈,`adc_kernel` 里 `pd_use_ffe` 且无 PR 时 `x = y_sl`),模型读的是 DFE 之前的样本。
  冻结环路(内核 kp/ki 置 2^-60、采样偏移钉在锁定点 ±1 / ±2 样本)实测增益 0.0276 V/UI,旧模型 0.0195;扣掉锁定点的 DFE 后光标
  (固定值 —— DFE 抽头适应比环路慢)、锁在峰值上后 0.032。指纹 53 Gb/s 合成链路上模型与冻结内核的定时函数在 ±3 个样本内逐点吻合。
  ROADMAP 原写"扣掉 DFE 消掉的光标更远、已回退"是每个相位都扣的版本。
- **噪声**:模型把逐符号方差当白噪声。`Σ x[n](s[n+1] − s[n−1])` 在块内等于 `Σ x[n]s[n+1] − x[n+1]s[n]` 加两个端项:相邻主光标抵消(PAM4 只剩
  内外电平幅度差那份,无 ISI 时 2h0²var|a|),慢环路积分的低频谱密度在两条链路上都只有方差的 1/5。白时钟、随机符号下自噪声实测
  0.0031 / 0.0065 / 0.0102 UI(示例 31 链路 kp_shift 5 / 7 / 9),按方差的模型 0.0084 / 0.0121 / 0.0235,按谱密度 0.0037 / 0.0054 / 0.0105。
- **码型**:PRBS13Q 每 8191 个符号重复,检测器的数据噪声是重复率整数倍上的谱线(112 GBd 下 13.7 MHz 起),在 1–2 MHz 的环路之外 ——
  同一链路 PRBS13Q 下自噪声只有 0.0003–0.0008 UI。时域引擎跑的是配置里的码型,所以模型也要按它算。

**做法**:`mm_pd_statistics(..., n_feedback, n_lanes, period_levels) -> (k_pd, PdNoise)`:增益照旧蒙特卡洛(改卷积、2^17 符号);噪声分两份 ——
接收噪声那份白(有噪 − 无噪的成对序列的低频谱密度),数据那份:码型给了周期就在 lcm(周期, n_lanes) 上算无噪块平均序列的 DFT 得谱线,
没给就按随机数据的低频谱密度。谱密度用成对序列 `x[n]s[n+1] − x[n+1]s[n]` 的自协方差求和到窗口跨度(更远的不共享符号,协方差为零),
估计 ±3–6 %(纯白、方差大于谱密度时 ±4 %)。`self_noise_ui` 对谱线逐条乘 `|H|²`。统计引擎 `_pattern_period` 从 `sim.pattern` 取周期
(PRBS-N,预编码可能翻倍;铺满整块后 > 2^21 符号的 —— PRBS31、PRQS10 —— 按随机)。

**结果**:示例 31 模型 / 实测 0.97–1.39× → 0.81–1.07×(SSPLL / CPPLL,kp_shift 4–9);112 GBd 测试(224G stress 预设)实测 / 模型
0.98 / 1.23 / 0.96,其中自噪声项 105–318 fs → 7–17 fs;统计 BER 对时域 kp_shift 8 处 0.4–0.5×、9 处 1.2–2.2×。时域引擎逐位不变;指纹只动合成 `adc_dsp/profile/stat`(σ 0.0202 →
0.0045 UI)。剩下的偏差在未跟踪项:模型增益比冻结环路高 1.17×,带宽读宽,mid-gain 处读低。

**线性模型看不到的两件事**:(1)合成链路的定时函数在锁定点后半个样本见顶,往后没有恢复力 —— PRBS13Q 下内核锁住,随机符号下漂走
7.7 UI,模型读 0.035–0.117 UI 不警告(ROADMAP P2 #26)。(2026-10-14 补:已查,见 §27 —— 拐点 0.42 个样本,随机符号上顶点略低于零;按拐点距离 / 环路游走 < 8× 警告。
另更正"PRBS13Q 下内核锁住":白时钟下 4/4 锁住,SSPLL 剖面下 kp_shift 6 有 1/4、8 起 3/4 失锁。)(2)慢环路的捕获很慢:同一链路 kp_shift 6 下时域误差在 40 万符号的四个四分之一段
里 0.0091 → 0.0061 → 0.0046 → 0.0036 UI(模型 0.0039);指纹那条只跑 6000 个符号,读的是捕获。
**附带**:示例 31 白时钟 4–5 个比特错而统计预期约 0.1 个,错误附近采样相位只偏 1–3σ —— 像是每个边沿的抖动过信道拖尾成了幅度噪声,
与 CDR 无关(ROADMAP P2 #25)。

## 26. 发端白抖动是逐沿噪声,不是采样时刻抖动(2026-10-14,ROADMAP P2 #25)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 31 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:统计引擎把发端 `rj_ui` 和接收端的一样,当采样时刻抖动在相位轴上抹 BER(φ);时域引擎(`tx/jitter.py`)每个边沿各自移动。
示例 31 白时钟(200 fs):时域 6 个种子 19 个错(8.2e-6,无抖动 0),统计 2.4e-7(0.03×)。0.03–0.09 UI 下五条链路统计 / 时域 0.00–0.10×。

**机理**:边沿 k 移动 ε_k,采样点多出 `Δb_k (s(t − kT − ε_k) − s(t − kT))`(s:DAC 之后整条链的阶跃响应,`Δb_k`:发端 PR / FFE 之后的跳变)。
公共的采样偏移线性化后有交叉项 −h_k h_(k+1),有损信道上几乎抵消;独立的逐沿位移没有,而且跟着跳变走(连续相同符号处为零、满幅跳变最大)。

**做法与逐步证据**(示例 31 链路 = 112 GBd stress 预设):
1. 线性化、一个方差:闭式 0.913 mV vs 时域实测 0.823 mV;BER 0.21×(数据相关的噪声尾巴比平均高斯厚)。
2. 按被采符号的前后邻居分箱(复用光噪声的 `pattern_sigma` 通道,被采符号自己的两个边沿在箱里固定):0.45×;ADC 预设 0.49–1.23×。
3. 混合信号 0.00–0.16× 不动。噪声大小是对的(NRZ 16G 模型 11–14 mV vs 实测 13.4 mV);冻结环路的时域浴盆(锁定点 6.7e-5)整体比统计高
   20–70×。蒙特卡洛(理想 DFE、统计锁定点)分清了原因:精确阶跃 5.8e-5、线性化 2.0e-6 —— 快信道的阶跃在几分之一 UI 内上升,3σ
   的位移把陡段拖到采样点上。只对被采符号自己的两个边沿精确、其余线性:5.8e-5(与全部精确相同;PAM4 32G 1.07e-4 vs 1.08e-4)。
4. 实现 `tx_edge_jitter` → `TxEdgeJitter`:每相位、每箱的线性 σ(给 PR 并集界 / 电压格)、其余的 σ、两个自身边沿的阶跃均值、
   位移网格上的 φ 与高斯权;`noisy()` 里每箱先过其余的高斯再直接卷积两个边沿的精确核(不用 FFT:舍入会在 1e-16 处给尾巴垫底)。
   相位轴只留接收端时钟的 RJ。线性项的斜率两侧取平均:`jittered_zoh` 面积守恒,边沿往后移的是边界后那个样本、往前是前那个。

**结果**:0.03–0.09 UI 发端 RJ,统计 / 时域(两种子 × 20 万符号):224G ADC 106 GBd 1.11 / 1.36 / 1.39×,112 GBd stress 0.69 / 1.22 / 1.29×;
示例 31 白时钟 0.55×;PAM4 32G 混合信号 0.47 / 0.67×(0.06 / 0.09 UI),NRZ 16G 0.38×(0.09 UI)。混合信号余下的是 BB 环路自身游走
(NRZ 16G 0.056–0.062 UI,PAM4 32G 0.025–0.040 UI):白噪钟统计引擎不建 CDR;把实测游走当模糊加上 0.83–0.90× → ROADMAP P2 #27。
白噪钟的 SJ / DCD 统计引擎仍不建(写进假设清单)。(2026-11-01 更正:已建,见 §40。)`tests/test_tx_edge_jitter.py`。

## 27. MM 定时函数在锁定点附近见顶:报拐点距离、按环路自己的游走警告(2026-10-14,ROADMAP P2 #26)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 31 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**问题**:§25 记的指纹 53 Gb/s 合成链路(ADC,0.2 m,发端 FIR −0.08 / 0.72 / −0.2):随机符号下时域 MM 环路漂走 7.7 UI,线性模型读
0.035–0.117 UI、不警告。

**机理**(探针在时域起点 FFE 上,模型与冻结内核的定时函数 ±1 样本内一致):均衡(MMSE FFE + 锁定点 h1 的 DFE)把定时函数在锁定点压到
零(码型上 ±2e-6),往晚的一侧 0.42 个样本(0.026 UI)就见顶,顶点只高出零约 2e-4(随机符号上还略低于零,−2e-4;冻结内核在 PRBS13Q
上 +3e-4)。过了拐点拉回力变弱,过了下一个零点反向,积分器把环路一直推下去 —— 时域里误差均值 +0.02 → +0.08 UI 慢慢爬,然后按平方
加速跑走(20 万符号 100 UI)。预设上拐点在 0.075–0.15 UI(106 GBd / 112 GBd stress / deep-LR / TI mismatch / LPO)。

**为什么不判"有没有零点"**:零点高度(2e-4)低于模型能分辨的量 —— 随机与码型、模型与冻结内核之间就差这么多;拐点的位置却稳
(2^16 符号、三个种子 ±1.5 %,2^18 时 ±0.4 %)。

**比什么**:能把环路本身带过拐点的是慢误差 —— 检测器自噪声加带宽内跟晚的时钟(`sigma_wander_ui`)。带宽外的时钟抖动环路不跟、只把
定时函数抹平:拿总 σ 比,示例 31 的 12 个设置(SSPLL / CPPLL 200 fs,kp_shift 4–9)全部 1.6–6.7×、全报警,时域都锁着;按游走 15–37×。

**标定**(合成链路,SSPLL 剖面,4 个种子 × 20 万符号,BER > 1e-3 记失锁):

| 码型 | kp_shift 4–10 的拐点 / 游走 | 时域 |
|---|---|---|
| PRBS7Q | 3.1–16.5× | 全部锁住 |
| PRBS9Q | 3.1–15.3× | 4.3× 与 3.1× 各 1/4 失锁,6.1× 起锁住 |
| PRBS13Q | 2.8–6.7× | 每格 1–3/4 失锁 |
| PRBS15Q | 2.8–6.9× | 每格 3–4/4 失锁 |
| PRBS31Q(随机;白时钟实测,kp_shift 4–12) | 0.1–0.7× | 全部失锁 |

失锁全在 ≤ 6.9×,8.6× 起没有 → 8× 警告。白时钟下更耐:PRBS13Q 到 1.4× 才见 1/4 失锁,PRBS7Q 到 1.4× 仍 4/4 锁住(白时钟统计引擎不建环路,不查)。剖面让
失锁提前的那份(时域里锁定点本身慢慢爬)线性的带内误差没有体现 —— 阈值是标定的,不是推出来的;跑得更长(> 20 万符号)逃逸只会更多。

## 34. 类的相位分布是投票链的不动点,不是平稳分布的平移(2026-10-26,ROADMAP P3 #14)

> 2026-10-30 起冲激按 ISI 尾巴截断(ROADMAP P1 #42),本节引用示例 24 的数字为之前的读数,重跑见 `examples/expected/`(结论级改动已在本节或 docs 里另注)。

**拆法(NRZ 16G 预设,8 mV + rj 0.019 为主,时域每跑 160 万符号)**:
1. 投票表先对齐内核。按(前串长 La, 本串长 Lb)分组比内核的 `pd_hist`:§33 的"每个真跳变投一票"在 La ≥ 4、Lb = 1 的类上读 +1.00,内核 +0.55 ——
   内核的 Alexander 鉴相器读 DFE **之前**的原始符号,长反向串后的孤立符号常被拉成反向电平,两条边都不投。改为 E[pd] = (E sgn y_old − E sgn y_new)·E sgn y_edge / 2、
   投票概率 (1 − E sgn y_old·E sgn y_new) / 2,三个样本各自条件化光标 + 其余高斯,再按发端边沿抖动平滑。拿冻结在 +2 / +4 / +6 / +8 个样本的内核逐类核:
   率与均值多在 0.02 内(+6 处 La = 4、Lb = 1 一格 +0.07 对 +0.19 最差),总体均值 −0.319 对 −0.315(+6)。
2. 窗内传播不够。从 p0 出发把窗里 12 条边逐条传播,类混合离 p0 最多 98 %(`marginal_error` 0.98):p0 是均值曲线的 Boltzmann 密度,不是投票自己的平稳分布。
3. 相邻两票共用一个原始样本。符号 i−1 的原始符号既是边 (i−2, i−1) 的新侧又是边 (i−1, i) 的旧侧:孤立符号读对就两票都投,读错就都不投。
   按独立抽的 Monte Carlo 早侧 8 个样本处比成对抽的重 3×。
4. 内核自己的相位记录还要两样:积分路径(从记录反推 I_k = d_(k+1) − d_k − kp·pd_k,残差 1e-7,RMS 0.0133 / 符号,与线性化环路的 Lyapunov 解 0.0135 一致)
   和码型。用投票表 + kp / ki 动态做 Monte Carlo:喂内核自己的 PRBS31 段,相位直方图逐格 0.89–1.09×(到 10 个样本)、P(d > 8.5) 3.75e-5 对 3.70e-5,
   E[pd | d]、投票率、E[I | d]、各相位上的 La 分布全部对上;喂独立随机码元 P(d > 8.5) 5.6e-6、PRBS13 7e-7、PRBS7 0。时域内核本身换独立码元:
   70 种子 P(d > 8.5) 4.3e-6 —— 与 Monte Carlo 同量级(1.3×)。即深处的相位尾有一大半是 PRBS31 的递推(x_k = x_(k−28) ⊕ x_(k−31))落在环路记忆长度上(见第 6 条)。

**模型(`_pattern_phase_factor`)**:状态 = 类(i 之前 12 个符号 + 下一个,均相对 i)× 相位 × "上一个数据样本读对没有";一步追加一个等概符号,按第 1 条的表在质量所在的相位上投票
(kp 一格,网格取 kp 的整分之一,默认 0.5 个样本),跑到尾巴按自身相对变化 < 1e-3 的不动点(NRZ 16G 120–180 步)。不含积分路径(状态翻倍)和码型相关,

## 40. 统计引擎建白 SJ 与 DCD(2026-11-01,ROADMAP P2 #45;JTOL 可走统计引擎)

**为什么**:顶部近似清单原写"白 SJ 与 DCD 不建",统计引擎在带宽以上 0.04–0.1 UI SJ 下读 0.04–0.31×、DCD 下 0.04–0.81×,JTOL 只能走时域(深门限够不到)。

**SJ**(`stat_loop.sj_tones` / `sj_phase_offsets`,`cdr.linear` 两个环路解的 `tones`):两侧时钟的音都过同一个误差响应(环路跟的是两者之差),留下 `A |E(f)|`(`LoopSolution.sj_residual`);

## 42. 时域 mixed-signal 的启动过渡:锁定点取初值、训练段电平换挡(2026-11-01,ROADMAP P2 #45 的后续)

**问题**:§40 末查出 DCD 下时域短运行数进了电平收敛的过渡期;再拆一层,过渡有两个来源。① DFE 抽头和判决电平取在**脉冲峰值**的光标上,
bang-bang 环路却锁在它后面(PAM4 32G 2 个样本):tap1 从 −0.017 起步、sign-sign 40 万码元才走到 −0.029(锁定点处的光标是 −0.0308),
**不加 DCD 也在**;② DCD 这类起点不知道的电平偏移(5–10 mV)按跟踪步长要 1e5–1e6 码元,训练段只有 4000。

**改动**:`DfeConfig.init` 加 `"lock"`(默认):在 `cdr.linear.lock_offset_samples(脉冲, 峰值, osr, osr/2)` 处取光标 —— 只用脉冲,两引擎仍独立;
`"cursor"` 是原来的峰值。统计引擎在 DFE 不自适应时原把门限放在峰值的主光标上(跟着时域),现在 `init="lock"` 时也放在锁定点。
`DfeConfig.train_gain`(默认 1):训练段里**电平**的步长倍数。抽头不乘:眼闭合的链路(NRZ,−16 dB 串扰,BER 0.2)上抽头乘 64 时 tap1 跑到 1.16;
电平乘 64 时同一条链路的 slicer SNR 掉 8 dB、两种噪声抽样差 1.5 dB,所以默认不开。

**效果**(PAM4 32G,8 种子 × 30 万码元,BER 头 2.5 万 / 20 万之后):7 mV 无 DCD 2.8e-5 / 1.1e-5 → 1.3e-5 / 1.1e-5(锁定点初值,整段 1.47e-5 → 1.08e-5);
0.12 UI DCD、6 mV:原 1.6e-4 / 2.7e-5,锁定点初值 1.3e-4 / 2.7e-5,再加 `train_gain` 64 为 3.0e-5 / 1.9e-5(整段 6.3e-5 → 5.1e-5 → 2.1e-5)。
预设的 slicer SNR 变化在 0.01 dB 量级(按峰值取的电平原来离锁定点处的幅度远一点)。NRZ 预设锁定点与峰值落在同一个样本上,不变。
PAM8 / PAM6 mixed-signal 的统计 / 时域对照:时域误码变少后统计读高 3.6–6.3×,把统计引擎的门限也挪到锁定点后回到 2× 内。
